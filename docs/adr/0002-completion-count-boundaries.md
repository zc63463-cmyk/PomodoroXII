# 完成度计数：直接子项、分母为空与本地派生

**状态**：已接受（2026-09-11）

延续 ADR-0001（只做计数、不做百分比）。本裁定固定三处边界，避免实现时各自发明：

- **作用域**：只统计**直接子项**（L1 数 L2、L2 数 L3），不递归后代。理由：工作台设计稿原文即「直接完成数 / 有效直接子项数」（`WORKITEM_WORKBENCH_REVIEW.md:93`）；递归会把父项数字变成"孙辈完成情况"，无法解释。
- **分母为空（N/A）**：**存在直接子项且 `valid === 0`（全部取消）** → 显示「**范围已取消**」，不出数字；**尚无直接子项** → 留空。任何情况下不显示 `0/0`、`0%`、`100%`，界面不出现「N/A」字串。
- **派生位置**：前端本地纯函数 `deriveCompletionCounts(nodeId, items) → { completed, valid, cancelled }`，不落库、不进同步、不加服务端端点。理由：work_item 已在本地全量缓存（离线可用、零请求）；「未完成子项数」现即本地推导，属同一范式；服务端端点等出现第二个消费者（MCP / Saved View / 筛选）再补。
- **100% 语义**：`completed === valid > 0` 时仅给非模态完成提示与完成色，不自动完成父项，不提供一键完成（父项生命周期 / 撤销 / 审计成本另立项）。

**呈现约定**：树行徽标由「N 子」升级为 `X/Y`；详情面板显示 `X/Y` + 已取消 N；部分取消时取消数只出现在 hover 与详情；工作台可选列暂不做。
